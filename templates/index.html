About Project

GlucoAI is an AI-powered diabetes prediction system developed using Machine Learning, Python, Flask, MySQL, HTML and CSS. It predicts whether a patient is diabetic using medical parameters like Age, BMI, HbA1c Level, Blood Glucose Level, Smoking History, Hypertension and Heart Disease.
